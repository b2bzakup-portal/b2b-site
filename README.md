# B2B портал агробизнеса — прототип интерфейса

Кликабельный прототип портала оптовых закупок `b2bzakup.ru`: все страницы на тестовых данных, десктоп и мобильная версии.

## Стек

Next.js 15 (App Router), TypeScript, Tailwind CSS 4, shadcn/ui. Пакетный менеджер — pnpm, Node.js 22 и новее.

## Команды

```
pnpm install       # зависимости
pnpm dev           # локальная разработка, http://localhost:3000/b2b-site/
pnpm build         # статический экспорт в out/
pnpm export:docs   # копирует out/ в docs/, откуда сайт отдаёт GitHub Pages
pnpm typecheck     # проверка типов
pnpm lint          # ESLint
```

## Структура

| Папка | Что лежит |
|---|---|
| `app/` | маршруты и страницы |
| `components/` | компоненты интерфейса; `components/ui/` — база shadcn/ui, настроенная под дизайн-систему |
| `lib/` | общие функции |
| `fixtures/` | тестовые данные прототипа |
| `scripts/` | служебные скрипты сборки |
| `docs/` | опубликованная статика: экспорт прототипа, дизайн-система и страница хода работ |

Дизайн-токены объявлены один раз в `app/globals.css`; в компонентах используются только они.
